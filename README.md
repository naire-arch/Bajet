# Bajet by Waziri
East African Meal Planner & KES Grocery Budget Web App.

## How to Run
- **Locally:** Unzip the folder and double-click `index.html` to open it in any browser.
- **On GitHub Pages:** Upload all files inside this folder (`index.html`, `style.css`, `data.js`, `app.js`, `manifest.json`) to your GitHub repository root, go to **Settings -> Pages**, choose the `main` branch, and click **Save**.
